VictoriaBank e-Gateway

Developer Integration Guide

Overview

VictoriaBank e-Gateway is a hosted payment processing service for Visa, Mastercard, and StarCard payments. The merchant's server builds a signed HTML form and redirects the customer's browser to the bank's secure payment page. After authorization, the bank sends two notifications:

  • Server callback (Callback URL) — a server-to-server HTTP POST with transaction result, sent directly to your registered callback endpoint.
  • Browser redirect (BACKREF URL) — the customer's browser is redirected back to your site with transaction result parameters.
Important: Always process the result from the server-side callback, not from BACKREF. The BACKREF redirect can be manipulated or may never arrive if the customer closes the browser. The callback is authoritative.

Обзор

VictoriaBank e-Gateway — это сервис для обработки платежей по картам Visa, Mastercard и StarCard. Сервер продавца формирует подписанную HTML-форму и перенаправляет браузер покупателя на защищённую платёжную страницу банка. После авторизации банк отправляет два уведомления:

  • Серверный callback (Callback URL) — HTTP POST между серверами с результатом транзакции, отправляется напрямую на ваш зарегистрированный callback-эндпоинт.
  • Редирект браузера (BACKREF URL) — браузер покупателя перенаправляется обратно на ваш сайт с параметрами результата транзакции.
Важно: Всегда обрабатывайте результат из серверного callback, а не из BACKREF. BACKREF-редирект может быть подделан или не прийти, если покупатель закрыл браузер. Callback является авторитетным источником.

RSA Keys

The e-Gateway uses RSA-2048 with SHA-256. You need two key files:

  • Your private key (merchant_private.pem) — generated by you. Used to sign outgoing payment requests (P_SIGN). Keep it secret, outside the web root.
  • Your public key (merchant_public.pem) — sent to VictoriaBank to register your terminal. The bank uses it to verify your signatures.
  • Bank's public key (victoria_pub.pem) — provided by VictoriaBank. You use it to verify P_SIGN in all incoming callback notifications.

P_SIGN Algorithm

P_SIGN is your RSA-SHA256 digital signature that authenticates each request to the bank and verifies each callback from the bank.

MAC String Construction

For each field in the required order, append: length(value) + value. If a field is empty or "-", append just "-" (no length prefix). Concatenate all results.

Algoritmul P_SIGN

P_SIGN este semnătura ta digitală RSA-SHA256 care autentifică fiecare cerere către bancă și verifică fiecare callback de la bancă.

Construirea șirului MAC

Pentru fiecare câmp în ordinea necesară, adaugă: lungime(valoare) + valoare. Dacă un câmp este gol sau "-", adaugă doar "-" (fără prefix de lungime). Concatenează toate rezultatele.

Алгоритм P_SIGN

P_SIGN — это ваша цифровая подпись RSA-SHA256, которая аутентифицирует каждый запрос в банк и проверяет каждый callback от банка.

Формирование MAC-строки

Для каждого поля в требуемом порядке добавьте: длина(значение) + значение. Если поле пустое или равно "-", добавьте просто "-" (без префикса длины). Объедините все результаты.

// Build MAC string. Empty or '-' fields -> '-' (no length prefix).
function buildMac(fields) {
  return fields.map(f => (f === '' || f === '-') ? '-' : `${f.length}${f}`).join('');
}

function psignGenerate(order, nonce, timestamp, trtype, amount, privateKeyPem) {
  const mac = buildMac([order, nonce, timestamp, trtype, amount]);
  return crypto.sign('sha256', Buffer.from(mac, 'utf8'), {
    key: privateKeyPem,
    padding: crypto.constants.RSA_PKCS1_PADDING,
  }).toString('hex').toUpperCase();
}

// Verify bank callback P_SIGN.
// Fields order: ACTION, RC, RRN, ORDER, AMOUNT (empty fields -> '-')
function psignVerifyCallback(params, bankPublicKeyPem) {
  const pSign = (params.P_SIGN || '').trim();
  if (!pSign) return false;
  const fields = ['ACTION','RC','RRN','ORDER','AMOUNT'].map(k => (params[k] || '').trim());

  try {
    return crypto.verify('sha256', Buffer.from(mac, 'utf8'),
      { key: bankPublicKeyPem, padding: crypto.constants.RSA_PKCS1_PADDING },
      Buffer.from(pSign, 'hex'));
  } catch { return false; }
}

public class PSignUtils {

    /** Build MAC. Empty/'-' fields -> '-', no length prefix. */
    public static String buildMac(String... fields) {
        StringBuilder mac = new StringBuilder();
        for (String f : fields) {
            if (f == null || f.isEmpty() || f.equals("-")) mac.append('-');
            else mac.append(f.length()).append(f);
        }
        return mac.toString();
    }

    /** Generate P_SIGN for outgoing request (TRTYPE=0/21/24). */
    public static String psignGenerate(String order, String nonce, String timestamp,
                                        String trtype, String amount, PrivateKey pk) throws Exception {
        String mac = buildMac(order, nonce, timestamp, trtype, amount);
        Signature sig = Signature.getInstance("SHA256withRSA");
        sig.initSign(pk);
        sig.update(mac.getBytes("UTF-8"));
        return bytesToHex(sig.sign()).toUpperCase();
    }

    /** Verify bank callback P_SIGN. Fields: ACTION, RC, RRN, ORDER, AMOUNT */
    public static boolean psignVerifyCallback(Map<String,String> p, PublicKey pubKey) throws Exception {
        String pSign = p.getOrDefault("P_SIGN","").trim();
        if (pSign.isEmpty()) return false;
        String mac = buildMac(
            p.getOrDefault("ACTION",""), p.getOrDefault("RC",""),
            p.getOrDefault("RRN",""),    p.getOrDefault("ORDER",""),
            p.getOrDefault("AMOUNT",""));
        Signature sig = Signature.getInstance("SHA256withRSA");
        sig.initVerify(pubKey);
        sig.update(mac.getBytes("UTF-8"));
        return sig.verify(HexFormat.of().parseHex(pSign.toLowerCase()));
    }

        byte[] b = new byte[20]; new SecureRandom().nextBytes(b);
        return bytesToHex(b).toUpperCase();
    }
    public static String generateTimestamp() {
        return DateTimeFormatter.ofPattern("yyyyMMddHHmmss")
               .format(ZonedDateTime.now(ZoneOffset.UTC));
    }
    public static String formatOrderId(int id) { return String.format("%06d", id); }
    public static String formatAmount(double amt) { return String.format("%.2f", amt); }

        StringBuilder sb = new StringBuilder();
        for (byte x : b) sb.append(String.format("%02x", x));

    }

Callback Notification

After processing the payment, VictoriaBank sends a server-to-server HTTP POST to your registered Callback URL. This happens for both successful and failed transactions.

Always respond HTTP 200. Any other status code may cause the bank to retry. Return 200 even when rejecting an invalid P_SIGN.

Callback POST Fields

Notificarea Callback

După procesarea plății, VictoriaBank trimite un HTTP POST server-to-server la URL-ul tău de Callback înregistrat. Acest lucru se întâmplă atât pentru tranzacțiile reușite, cât și pentru cele eșuate.

Răspunde întotdeauna cu HTTP 200. Orice alt cod de stare poate cauza retrimiterea de către bancă. Returnează 200 chiar și când respingi un P_SIGN invalid.

Câmpurile POST de callback

Callback-уведомление

После обработки платежа VictoriaBank отправляет HTTP POST между серверами на ваш зарегистрированный Callback URL. Это происходит как для успешных, так и для неудачных транзакций.

Всегда отвечайте HTTP 200. Любой другой код состояния может привести к повторной отправке банком. Возвращайте 200 даже при отклонении невалидного P_SIGN.

Success Criteria

Both conditions must be true for an authorized transaction:

  • ACTION = 0
  • RC = 00

Only then proceed to TRTYPE=21 (Sales Completion). Save RRN and INT_REF — required for TRTYPE=21 and TRTYPE=24.

Criterii de succes

Ambele condiții trebuie să fie adevărate pentru o tranzacție autorizată:

  • ACTION = 0
  • RC = 00

Numai atunci treci la TRTYPE=21 (Finalizare vânzare). Salvează RRN și INT_REF — necesare pentru TRTYPE=21 și TRTYPE=24.

Критерии успеха

Оба условия должны быть выполнены для авторизованной транзакции:

  • ACTION = 0
  • RC = 00

Только после этого выполняйте TRTYPE=21 (Завершение продажи). Сохраните RRN и INT_REF — они нужны для TRTYPE=21 и TRTYPE=24.
